# Speroni Irrigation — Website Concept

A responsive, single-page website concept for the Bulawayo Speroni Irrigation branch, built as a lightweight static site so it can be deployed directly on Vercel.

## Included

- Actual Speroni logo image, sourced from the company's existing website.
- Bulawayo contact information from the supplied advert: **+263 712 768 474**, **52 Plumtree Road, Belmont, Bulawayo**.
- Hero section with water-drilling video background.
- Irrigation section with a separate aerial irrigation video.
- Services: borehole survey/siting, drilling, flushing and installation, drip and overhead irrigation, water reticulation, borehole capacity testing, pumps, repairs and maintenance.
- Homes / farms / plots / businesses audience sections.
- Project process, FAQs, contact section and map.
- Responsive navigation, WhatsApp contact shortcuts and a quotation form.
- The quote form validates required fields and builds a pre-filled WhatsApp enquiry for the visitor to review and send.

## Deploy on Vercel

1. Sign in to Vercel and choose **Add New → Project**.
2. Import `ncubemphile8/Speroni-borehole-drilling-and-irrigation-`.
3. Keep the framework as **Other** (static site).
4. Leave the build command and output directory empty; `index.html` is at the repository root.
5. Select **Deploy**.

No Node packages or build step are required.

## Important before launch

- This is a **website sample / concept**, not a verified production website.
- The phone number and Bulawayo address are reproduced from the supplied Speroni advert. Confirm with the company that the number and address are current before publishing.
- Speroni's public Zimbabwe website was used to verify and expand the service descriptions. The sample keeps the advert's Bulawayo contact details as its primary contact route.
- The drilling and irrigation videos and some supporting photographs are representative stock visuals, not claims that the scenes show Speroni staff or completed Speroni projects. Replace them with company-owned footage/photos before a final production launch.
- The form opens WhatsApp with a pre-filled message to **+263 712 768 474**. It does not store form data or send it to a server.
- The map is an embedded Google Maps search for the advert's Bulawayo address; verify the exact pin before launch.
